# VenGo 4.97

GUILD POINTS, redone:

- **Fixed: the items never loaded.** VenGo only fetched them with its half-hourly website update, so after an update
  the tab stayed empty for up to 30 minutes. It now fetches them straight away (and tries again every minute until it
  has them).
- **A craft menu**: the nine crafts in a menu on the left, drawn like VenGo's own menu (in every style), with your
  rank in each beside it. VenGo remembers the one you picked.
- On the right, the chosen craft's items for **every rank**, each rank in its own box with the items it trades and
  each item's points and daily maximum. **Your rank is marked in gold.** Item names link to catseyexi.com/database.
- Today's pattern letter and the reset countdown at the top, and a WEBSITE button for catseyexi.com/events.
