# VenGo 4.85

Performance. Nothing looks different except far-away rune circles, which are simpler.

- **GPS, every style:** the screen's size was read from the game once for every point drawn (hundreds a frame). It
  is now read once a frame.
- **RUNES:** circles that are off the screen are no longer drawn. Far ones are one ring and the star; the fine rune
  marks are kept for the ones close to you. About 30% fewer shapes with the whole path in view, more when part of
  it is off screen. With Glow passes 1 (or Light mode) it also drops its filled glow and inner ring.
- **LIGHT and AETHER:** lengths of the path that are off the screen are skipped.
- **Japanese and window scale:** the hooks these put on drawing are now taken off again when you are in English at
  100%. Before, once either had been used, every shape drawn went through them until you reloaded.
- **Spark vendor tab:** the search for the Sparks NPC read 1,023 names every frame. It now runs once a second.
- **Neon style:** its filled shapes no longer make a new function and a protected call each; the honeycomb draws
  fewer lines.
- Venture rows look their crest up once instead of every frame.
