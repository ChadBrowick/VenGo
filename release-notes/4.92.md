# VenGo 4.92

- **LB + Y opens VenGo with the controller** (L1 + Triangle on a PlayStation pad), and pressing it again closes it.
  - While VenGo has the controller, **LB / RB** change to the menu before / after (round the ends).
  - **B** closes VenGo and gives the controller back to the game. While you're changing a slider or a box, B
    cancels that first.
  - **Back / Select** still gives the controller back and leaves VenGo open.
- On by default; switch it off with "LB + Y opens VenGo" in Settings > Controller.
- LB on its own still goes to the game while VenGo doesn't have the controller, and a button's release always goes
  where its press went, so the game never sees a button stuck down.
