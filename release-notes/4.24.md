**Download:** VenGo-v4.24.zip below (under Assets).

**Faster Venture Seal pickup**
- The Seal's spot is now checked every 0.25 s and the whole list searched every 0.5 s by default (was 0.5 s and 2 s), and both are adjustable.

**New: sliders for every number** (Settings)
- **Arrows:** Size, Spacing, Speed, Reach.
- **Performance:** Venture Seal check and search intervals, how often the camera is read, glow passes.
- Lightweight mode is now a one-click preset for the Performance sliders.

**New: three preset slots** (Settings → Presets)
- SAVE keeps every setting (colours, arrows, performance, alerts, window); LOAD puts them all back.

Unzip so you have `VanaCore\addons\ashita\vengo\vengo.lua` (or `addons\vanacore\vengo`), then `/addon reload vengo`.
