# VenGo 4.69

Fixes for the trouble since the server restart of 11 November.

- **Alerts no longer flap.** The website's clock came back 14 hours ahead, which made VenGo think the daily reset had
  already passed, so it asked the website every 5 minutes and let its numbers run over the game's own board. That is
  what produced "VNM ALERT" / "no longer at 100%" over and over. Now:
  - the game's board is the live one: the website's % is only used when the game hasn't sent a board for 15 minutes;
  - an alert from Populox's own callout only closes on a drop once the board has shown 100% during it;
  - after an alert closes, the board can't raise a new one for that VNM for 10 minutes (Populox still can).
- **Reset timer.** When the website's clock is wrong, its reset time is read against your PC's clock. If that still
  comes out in the past, VenGo uses the next 15:00 UTC (midnight in Japan).
